# M4 behavioural cloning environment (.venv-bc)
#
# A THIRD environment, and the reason is Principle VI rather than convenience:
#
#   .venv            numpy 1.26.4, pandas, scipy, matplotlib, NO torch   <- M1's committed numbers
#   .venv-mlagents   numpy 1.23.5, torch 2.6.0+cu124, NO pandas          <- RL training, M3
#   .venv-bc         this file                                           <- M4
#
# Neither existing environment can run M4: one has the dataframe stack and no torch, the other
# has torch and no dataframe stack. Installing torch into .venv invites pip to move numpy off
# 1.26.4, which would silently invalidate M1's reproducibility claim; installing pandas into
# .venv-mlagents disturbs the numpy 1.23.5 pin that mlagents hard-depends on. See
# specs/004-bc-baseline/research.md R1.
#
# Exact pins, not ranges. A range reconstructs a different environment next month, and
# Principle VI requires a reader to reconstruct THIS one.
#
# Install:
#   py -3.10 -m venv .venv-bc
#   .\.venv-bc\Scripts\python.exe -m pip install -r requirements-bc.txt
